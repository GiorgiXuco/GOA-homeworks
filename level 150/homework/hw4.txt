4) რატომ არ უნდა შევცვალოთ state პირდაპირ? (მაგ. count++)

State პირდაპირ შეცვლა არ შეიძლება, რადგან:

React ვერ ამოიცნობს ცვლილებას – state-ის პირდაპირი მოდიფიკაცია არ იწვევს კომპონენტის rerender-ს.

მონაცემთა თანმიმდევრულობა ირღვევა – React მუშაობს state-ის "queue"-თი და მისი მართვა ხდება setState/setCount-ის მეშვეობით.

ბაგების წარმოშობა – პირდაპირი ცვლილება იწვევს არაპროგნოზირებად ქცევას, რადგან რეალური state და React-ის მიერ დამახსოვრებული state ერთმანეთს აღარ დაემთხვევა.
