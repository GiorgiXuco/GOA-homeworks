3) როდის ვიყენებთ ternary operator ს React ში და რა უპირატესობა აქვს მას ჩვეულებრივ if else თან შედარებით

Ternary operator React-ში (და ზოგადად JavaScript-ში) გამოიყენება მაშინ, როცა გვჭირდება პირობითი რენდერი (conditional rendering) JSX-ში.

მას აქვს if else-ს თან შედარებით მოკლე და კონსიზური სინტაქსი → JSX-ში არ გვიწევს ცალკე if ბლოკის დაწერა.
