რა არის props.children?

React-ში ყველა კომპონენტს შეუძლია მიიღოს არა მხოლოდ კონკრეტული props-ები (title, color და ა.შ.), არამედ შიგნით გადაცემული JSX კონტენტი. ეს კონტენტი ავტომატურად ინახება props.children-ში.

ანუ, children არის სპეციალური prop, რომელიც წარმოადგენს იმ ყველაფერს, რასაც კომპონენტის გახსნისა და დახურვის ტეგებს შორის ჩავსვამთ.

რისთვის ვიყენებთ?

Reusable wrapper კომპონენტებისთვის (მაგ. ბარათი, მოდალი, ლეიაუტი).

Content injection: როცა გვინდა, რომ კომპონენტმა მიიღოს შიგთავსი, მაგრამ მისი შინაარსი წინასწარ არ ვიცით.

Composition: კომპონენტების მოქნილად გაერთიანებისთვის.

როდის ვიყენებთ?

როდესაც გვინდა, რომ კომპონენტმა თავისი სტრუქტურა და სტილი შეინარჩუნოს, მაგრამ შიგთავსი დინამიურად შევცვალოთ.

მაგალითად: Card, Modal, Layout, Button with icon.

როგორ ვიყენებთ?
მაგალითი: Card კომპონენტი
function Card({ children }) {
  return (
    <div style={{
      border: "1px solid #ccc",
      padding: "16px",
      borderRadius: "8px",
      backgroundColor: "#f9f9f9"
    }}>
      {children}
    </div>
  );
}

// გამოყენება
export default function App() {
  return (
    <div>
      <Card>
        <h2>სათაური</h2>
        <p>ეს არის ბარათის შიგთავსი, რომელიც props.children-ით გადმოიცემა.</p>
      </Card>

      <Card>
        <button>ღილაკი ბარათში</button>
      </Card>
    </div>
  );
}
